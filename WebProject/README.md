# 因材智学管理端

基于 Vue 3、TypeScript、Vite、Pinia、Vue Router 与 Element Plus 的 Web 前端管理端工程骨架。

## 快速开始

```bash
npm install
npm run dev
```

## 目录说明

- `src/router`：路由与守卫。
- `src/stores`：用户、布局等全局状态。
- `src/service`：Axios 请求、错误处理、上传和 SSE 基础封装。
- `src/layouts`：后台主布局、顶部栏、侧边栏和内容区。
- `src/components`：通用组件、业务组件、表格、图表、表单和预览组件。
- `src/views`：管理后台页面。
